عداد النسبة مع الساعة — PWA + APK

1) ارفع كل الملفات لـ GitHub (الملفات العادية بـ Upload files).
2) أنشئ الملف .github/workflows/build-apk.yml (Add file > Create new file، وكتب المسار كامل)، والصق فيه محتوى build-apk.yml.
3) فتبويب Actions غادي يبدا البناء أوتوماتيكيا (3-6 دقايق).
4) من بعد، فتبويب Releases (جنب Code) غادي تلقى nisba.apk. حملو من الهاتف وثبتو.
