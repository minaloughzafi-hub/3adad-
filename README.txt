عداد النسبة مع الساعة — PWA

الملفات: index.html, style.css, app.js, manifest.json, service-worker.js, icon.svg

العداد يزيد عند الضغط في أي مكان على الشاشة (ما عدا أزرار الألوان وزر RESET)، من 0 إلى 1000، ويعرض النسبة المئوية.
زر RESET يعيد العداد إلى صفر ويعيد اللون إلى الأزرق.

النشر على GitHub Pages:
1. ارفع كل الملفات إلى المستودع (Add file > Upload files).
2. Settings > Pages > اختر الفرع main.
3. افتح الرابط في Chrome على الهاتف ثم "Add to Home screen" أو "Install app".
