عداد النسبة مع الساعة — PWA

الملفات: index.html, style.css, app.js, manifest.json, service-worker.js, icon.svg, icon-192.png, icon-512.png, icon-maskable-512.png

العداد يزيد عند الضغط في أي مكان على الشاشة (ما عدا أزرار الألوان وزر RESET)، من 0 إلى 1000، ويعرض النسبة المئوية.

النشر على GitHub Pages:
1. ارفع كل الملفات (بما فيها ملفات png) إلى المستودع (Add file > Upload files).
2. Settings > Pages > اختر الفرع main.
3. افتح الرابط في Chrome على الهاتف ثم اختر "Install app" (ماشي "Add to Home screen").

عند أي تعديل: بدّل رقم CACHE_NAME فـ service-worker.js (v4 → v5).
